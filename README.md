# 做单工具 - 订单生成工厂生产表格

一款用于将店小秘导出的订单数据转换为工厂生产表格的工具。

## 📁 项目结构

```
做单工具/
├── 做单工具.exe           # 主程序（双击即可运行）
├── templete.xlsx         # 订单模板文件
├── 店小秘导出订单表/       # 店小秘导出的订单文件夹
│   └── *.xlsx            # 订单文件
├── 工具输出工厂单/         # 输出文件夹（自动创建）
└── README.md             # 使用说明
```

## 🚀 快速开始

### 方法一：直接使用（推荐）

1. **下载项目**：克隆或下载此仓库到本地
2. **放置模板**：将 `templete.xlsx` 模板文件放在项目根目录
3. **准备订单文件**：将店小秘导出的订单 xlsx 文件放入 `店小秘导出订单表` 文件夹
4. **运行程序**：双击 `做单工具.exe`
5. **查看结果**：生成的订单表格会保存在 `工具输出工厂单` 文件夹中

### 方法二：开发环境运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行程序
python src/main.py
```

## 📋 使用说明

### 步骤1：准备资源文件

确保项目结构如下：

```
做单工具/
├── 做单工具.exe
├── templete.xlsx            # 模板文件（必须存在）
└── 店小秘导出订单表/
    └── order_xxx.xlsx       # 店小秘导出的订单文件
```

### 步骤2：运行程序

双击 `做单工具.exe`，程序会自动：
- 扫描 `店小秘导出订单表` 文件夹中的所有 xlsx 文件
- 解析订单数据（支持中文和英文格式）
- 生成工厂生产表格
- 将结果保存到 `工具输出工厂单` 文件夹

### 步骤3：查看结果

生成的文件命名格式：`原文件名_result.xlsx`

## 📝 订单格式支持

### 支持的产品规格格式

**中文格式**：
```
颜色:Short sleeve top 1
尺寸:L
```

**英文格式**：
```
Size:L Color:Red
```

### 支持的尺码

- XS, S, M, L, XL, XXL, XXXL, XXXXL
- 2XL, 3XL, 4XL, 5XL

## 🛠️ 技术栈

- **Python 3.11+**
- **openpyxl** - Excel 文件处理
- **requests** - HTTP 请求
- **Pillow** - 图片处理
- **PyInstaller** - 打包工具

## 📌 注意事项

1. **模板文件**：`templete.xlsx` 必须存在于项目根目录
2. **订单文件**：必须放在 `店小秘导出订单表` 文件夹中，支持批量处理多个文件
3. **网络连接**：程序需要联网下载产品图片
4. **输出目录**：`工具输出工厂单` 文件夹会自动创建

## 🐛 常见问题

### Q: 程序双击后闪一下就消失？

**A**: 请确保 `templete.xlsx` 模板文件存在于项目根目录，`店小秘导出订单表` 文件夹存在且包含订单文件。如果问题仍然存在，可以在命令行中运行查看错误信息：

```bash
做单工具.exe
```

### Q: 某些订单没有被处理？

**A**: 程序会跳过无法解析的订单并显示警告信息。请检查订单的产品规格格式是否符合要求。

### Q: 如何更新工具？

**A**: 重新克隆仓库或下载最新版本即可。
