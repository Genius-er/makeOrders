# 做单工具 - 订单生成工厂生产表格

一款用于将店小秘导出的订单数据转换为工厂生产表格的工具，支持图形用户界面（GUI）操作。

## 📁 项目结构

```
做单工具/
├── src/
│   ├── gui_main.py          # GUI主程序
│   └── main.py              # 订单处理核心逻辑
├── templete.xlsx            # 订单模板文件
├── 店小秘导出订单表/         # 店小秘导出的订单文件夹（存放输入文件）
├── 工具输出工厂单/           # 输出文件夹（存放生成的工厂单）
├── .gitignore               # Git忽略配置
├── README.md                # 使用说明
├── build_gui.ps1            # GUI版本打包脚本
└── requirements.txt         # Python依赖配置
```

## 🚀 快速开始

### 方法一：直接使用（推荐）

1. **获取工具**：获取 `做单工具.exe` 可执行文件
2. **放置模板**：将 `templete.xlsx` 模板文件放在与 `做单工具.exe` 相同目录
3. **运行程序**：双击 `做单工具.exe`
4. **上传订单**：点击"选择文件"或拖入店小秘导出的订单文件
5. **选择输出**：确认或修改输出文件名（默认：原文件名_工厂单.xlsx）
6. **开始执行**：点击"开始执行"按钮
7. **查看结果**：生成的工厂单会保存到指定位置

### 方法二：开发环境运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行GUI程序
python src/gui_main.py
```

## 📋 使用说明

### 店小秘订单导出步骤

1. 登录店小秘后台
2. 进入 **订单** 页面
3. 勾选需要做单的订单
4. 点击 **导入/导出** → **导出勾选订单**
5. 选择 **按产品导出（每个产品导出一行）**
6. 选择 **标准模板**
7. 点击 **导出**

### GUI操作步骤

1. **上传订单文件**：
   - 方式一：点击"选择文件"按钮选择订单文件
   - 方式二：直接将订单文件拖放到上传区域

2. **设置输出文件**：
   - 程序会自动填充默认文件名（原文件名_工厂单.xlsx）
   - 可点击"浏览..."按钮修改保存位置和文件名

3. **开始执行**：
   - 点击"开始执行"按钮
   - 等待进度条完成（程序会下载产品图片并生成表格）
   - 完成后会显示保存路径

### 输出文件命名规则

默认格式：`原文件名_工厂单.xlsx`

示例：
- 输入：`order_20260519111437332_2279079.xlsx`
- 输出：`order_20260519111437332_2279079_工厂单.xlsx`

**中文格式**：
```

```

**英文格式**：

- XS, S, M, L, XL, XXL, XXXL, XXXXL
- 2XL, 3XL, 4XL, 5XL

## 🛠️ 技术栈

- **Python 3.11+**
- **openpyxl** - Excel 文件处理（支持数据验证/下拉菜单）
- **requests** - HTTP 请求（下载产品图片）
- **Pillow** - 图片处理
- **Tkinter** - 图形用户界面
- **TkinterDnD2** - 拖放功能支持
- **PyInstaller** - 打包工具

## 📦 打包方式

### 环境要求

- Python 3.11+
- 已安装依赖：`pip install -r requirements.txt`

### 打包命令

```bash
# Windows PowerShell
.\build_gui.ps1
```

打包完成后，可执行文件会生成在：
- 主文件：`dist/做单工具.exe`
- 同时复制到项目根目录：`做单工具.exe`

## 📤 分发方式

本工具采用**单文件分发**模式：

1. **分发内容**：
   - `做单工具.exe` - 主程序
   - `templete.xlsx` - 模板文件

2. **分发方式**：
   - 打包生成的 `做单工具.exe` 为独立可执行文件
   - 用户只需下载 `做单工具.exe` 和 `templete.xlsx` 即可使用
   - 无需安装 Python 环境或其他依赖

3. **目录结构（用户端）**：
   ```
   做单工具/
   ├── 做单工具.exe
   ├── templete.xlsx
   ├── 店小秘导出订单表/   # 用户存放订单文件（可选）
   └── 工具输出工厂单/     # 输出文件夹（自动创建）
   ```

## 📌 注意事项

1. **模板文件**：`templete.xlsx` 必须与 `做单工具.exe` 放在同一目录
2. **订单文件**：支持 .xlsx 格式的店小秘订单导出文件
3. **网络连接**：程序需要联网下载产品图片
4. **文件权限**：确保程序所在目录有读写权限
5. **数据验证**：生成的表格保留"名称"列的下拉菜单功能

## 🐛 常见问题

### Q: 程序双击后闪一下就消失？

**A**: 请确保 `templete.xlsx` 模板文件存在于程序同一目录。如果问题仍然存在，可以在命令行中运行查看错误信息：

```bash
做单工具.exe
```

### Q: 某些订单没有被处理？

**A**: 程序会跳过无法解析的订单并显示警告信息。请检查订单的产品规格格式是否符合要求。

### Q: 保存时提示权限错误？

**A**: 请确保保存路径所在目录有写入权限，或尝试更换保存位置。

### Q: 如何更新工具？

**A**: 下载最新版本的 `做单工具.exe` 和 `templete.xlsx` 覆盖原有文件即可。
